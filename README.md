# Xander Meyen: Portfolio

Persoonlijke portfolio website waarop ik mijn projecten, werkervaring en achtergrond als developer toon.

🔗 **Live:** [xandermeyen.be](https://www.xandermeyen.be)

---

## Pagina's

- **Home**: intro, uitgelichte projecten en navigatie
- **CV**: downloadbare PDF en skills carousel
- **Ervaring**: projecten, vaardigheden en werkervaring
- **Over Mij**: achtergrond, hobbys en persoonlijke eigenschappen
- **Contact**: contactformulier en directe links

## Tech stack

| | |
|---|---|
| HTML5, CSS3, JavaScript | Basis |
| Bootstrap 5.3 | Layout en componenten |
| Bootstrap Icons 1.11 | Iconen |
| Swiper | Skills carousel |
| Google Fonts | Montserrat & Open Sans |

## Lokaal uitvoeren

Geen build stap nodig. Clone de repo en open `index.html` in je browser.

```bash
git clone https://github.com/xandermeyen/portfolio.git
```
